# 💰 Finanzas360

**Finanzas360** es un sistema de control de gastos personales desarrollado con **React** y **Tailwind CSS**.  
Permite registrar ingresos y gastos, visualizar totales y saldo, y generar un gráfico circular de gastos por categoría.  

Ideal para practicar **JavaScript**, **POO**, **arrays**, **useState** y manejo de formularios.  

---

## ✨ Características

- 📝 Registro de **ingresos y gastos**.  
- 📊 Listado con **totales y saldo final**.  
- 🔍 Filtros por **categoría** o **fecha**.  
- 🎨 **Gráfico circular** de gastos por rubro.  
- 💻 Interfaz moderna con **Tailwind CSS**.  

---

## 🛠 Tecnologías

- **React**  
- **Tailwind CSS**  
- **Recharts** (para gráficos)  
- **Vite** (bundler y servidor de desarrollo)  
- **JavaScript**  

---

## 🚀 Instalación

1. Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
Entrar en la carpeta del proyecto:

cd Finanzas360


Instalar dependencias:

npm install


Esto instalará React, Tailwind CSS, Recharts y otras dependencias necesarias.

⚡ Levantar el proyecto

Para iniciar el servidor de desarrollo:

npm run dev

🗂 Estructura del proyecto

/src/assets/ → imágenes y logos.

/src/pages/ → componentes de página (Principal, GastoPorRubro, etc.).

/src/components/ → componentes reutilizables (Sidebar, Header, Footer).

/src/App.jsx → ruta principal del proyecto.

/tailwind.config.js → configuración de Tailwind.

/postcss.config.js → configuración de PostCSS.

📌 Uso

Completa el formulario para registrar ingresos y gastos.

Observa los totales y saldo final.

Visualiza el gráfico circular de gastos por rubro.

Usa el botón "Limpiar" para resetear el formulario.
